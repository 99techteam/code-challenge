# Problem 4: Three Ways to Sum to n

Three different implementations to calculate sum from 1 to n.

## How to Run

```bash
npx tsx demo.ts
```

## Files

- `sum_to_n.ts` - Main implementation with 3 solutions
- `demo.ts` - Demo script to test all functions

## Solutions

1. **sum_to_n_a** - Mathematical formula: O(1)
2. **sum_to_n_b** - Iterative loop: O(n)
3. **sum_to_n_c** - Recursive: O(n)
