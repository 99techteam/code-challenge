# My CRUD Project

## Overview

A simple CRUD (Create, Read, Update, Delete, Filter) application built with Node.js, TypeScript, Express, and Mongoose to manage products in a MongoDB database.

## Table of Contents

Features
Prerequisites
Installation
Running the Application

---

## Features

Create, read, update, delete and filter products.
RESTful API with Express.
Type safety using TypeScript.
MongoDB integration with Mongoose.

---

## Prerequisites

Node.js (version 18.x or higher recommended)
MongoDB (local installation or MongoDB Atlas)
npm (comes with Node.js)
Git (optional, for version control)

---

## Installation

1. Clone the repository:
   git clone
   cd
2. Install dependencies:
   npm install

---

## Running the Application

1. Ensure MongoDB is running (local: mongod, Atlas: check connection string).
2. Start the development server:
   npm run dev
